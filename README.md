A personal developer portfolio built with Next.js 16 (App Router), TypeScript, Tailwind CSS, and Framer Motion. Engineered with dark and light mode aesthetics, an interactive developer terminal, comprehensive project modals, and optimized for Vercel deployment.

---

## Key Features

- Interactive Developer Terminal: Built-in command terminal supporting custom commands (help, about, projects, skills, contact, clear).
- Dynamic Dark and Light Themes: System and user-toggled theme transitions with zero layout shift.
- Detailed Project Showcases: Interactive project modals with live demo links, GitHub buttons, and architectural deep-dives.
- Fluid Micro-Interactions: Custom spring animations, scroll spy navigation, and Canvas Confetti triggers.
- Recruiter Portal: CeoAuditModal provides quick high-level executive summaries and resume downloads.

---

## Tech Stack

- Framework: Next.js 16 (App Router, Turbopack)
- Language: TypeScript
- Styling: Tailwind CSS, PostCSS, Lucide Icons
- Animation: Framer Motion, Canvas Confetti

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/tanzim557/protfolio.git
cd protfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit http://localhost:3000 to view the live portfolio.
